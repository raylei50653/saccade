# Full-stack module subtraction (#418)

Diagnostic harness for the production-configuration interaction audit
([#418](https://github.com/raylei50653/saccade/issues/418)): runs the
`mamba_whole_graph` preset as `FULL`, then a **pre-declared** set of
leave-one-out subtractions (`FULL-A`), a few justified pair subtractions
(`FULL-A-B`), historical reference points and runtime-only toggles, and reduces
the run records into one summary read under rules fixed in the script header
before the first run. Production presets and sources are unchanged; every
variant is a CLI flag, an env override, or a derived `--config` copy of the
preset for keys the CLI cannot reach.

The harness owns no benchmark numbers: `FULL` is checked against the #421
production formal run by MOT-file md5, and every other row is an observed
difference against `FULL`. The reading of the results lives in
`docs/reference/benchmarks/module_interactions_20260921.md`; the relation
semantics live in `docs/architecture/module_interactions.md`.

## Run

From the repository root, under the `machine-bench` lease:

```bash
.venv/bin/python tools/resctl.py run --wait machine-bench -- \
  .venv/bin/python scripts/benchmarks/module_interactions/subtraction.py run \
    --root results/module_interactions_418/<stamp>

.venv/bin/python scripts/benchmarks/module_interactions/subtraction.py report \
  --root results/module_interactions_418/<stamp> \
  --json-output docs/reference/benchmarks/module_interactions_<date>.json \
  --markdown-output /tmp/module_interactions_tables.md
```

`run` is resumable (complete runs recorded in `manifest.json` are not
repeated); `--variants` selects a subset, `--kinds` selects by kind
(`full quality reference pair runtime`). Raw stdout/stderr, per-run record
JSON, MOT files and latency profiles stay under the run root (not tracked);
the committed artifact is the `report` JSON plus the reading document.
